# TCG Inventory

A demo-first stock management application for individual TCG sellers and small businesses.

**Stack:** Laravel 13, Livewire 4 (planned), Blade/Tailwind, custom UI. No Filament.

This repository is initialized from scratch. See `docs/` for setup, scope, demo journey, and phased implementation. The current development state will be maintained here as files are added.

## Development targets

- Singles and sealed products, variant-based stock tracking
- Receipt batches, stock adjustments, auditable movement ledger and FIFO costing
- Simple owner workspace and isolated demonstration data
- Demo-first inventory overview and transaction experience

## Setup

See `docs/06-setup.md`. Never use demo seed/reset commands on production data.
